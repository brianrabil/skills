# Sentence surgery

## Find the target

Read the current artifact. Bind the request to a specific occurrence, not a global search-and-replace. If the user says “the second sentence,” resolve it from the selected passage; abbreviations, fenced code, and repeated text can make punctuation-based guessing unsafe. Ask only when the available selection and context cannot identify the target.

Capture the base text before editing. For a file edit, use a source-range or unique exact replacement rather than parsing and reserializing the whole document. Preserve original line endings, frontmatter, indentation, and adjacent text. If an editor supplies a revision-bound request, produce the requested patch proposal against that exact revision; do not bypass its guarded import path with a direct write. If no such runtime exists, describe the scope as an instruction, not an enforced guarantee.

## Hold substance fixed

List the sentence's subject, action, conditions, quantities, negations, and degree of certainty. Mark exact API terms, quotations, and code separately. “May,” “must,” and “only after” can carry requirements; they are not filler by default.

Choose clearer syntax while retaining each commitment. Prefer the smallest effective change. For alternatives, vary expression within the same commitments and return the requested number; do not choose and apply one unless authorized.

## Check the edit

Compare base and result at the authorized occurrence. Text before and after the target must remain identical; every protected occurrence within the target must remain exact. A unique replacement is not sufficient evidence until the resulting diff has been inspected. If the artifact changed concurrently, re-read and reconcile the target rather than applying an old replacement.

Then assess meaning separately: did the actor, action, obligation, exception, condition, quantity, or uncertainty change? This is editorial assessment, even when a model performs it. If the answer is uncertain, provide the candidate as a proposal and name the concern rather than declaring proven equivalence.

## Finish proportionally

For a short passage, return the replacement and a compact diff or precise description of what changed. For a file edit, name the target and checks actually performed. A blocked preservation check remains blocked. If the task is proposal-only, leave the original untouched. No new style guide, persistent preferences, formatting pass, or delivery action follows from rewording.
