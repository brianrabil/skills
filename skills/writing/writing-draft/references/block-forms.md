# Block forms

The form arguments for [`writing-draft`](../SKILL.md)'s nonfiction branch:
choose the rendering of each block deliberately and out loud. The wrong form
hides a right argument.

## Prose vs list

Prose carries argument; lists carry parallel items. If the items aren't truly
parallel — if each needs its own connective tissue — prose is better. If they
are, a list is faster to scan and each item gets its own breath. A list of
non-parallel items is an argument someone chopped up; a list where items depend
on each other is an argument disguised as inventory.

## Table vs repeated structure

Same shape repeating three or more times with the same fields → table. Two
instances → prose with bold leads, or a short list. A table with one row is a
sentence wearing a costume; a table with six columns is a database, not a
paragraph.

## Quote vs paraphrase

Quote when the original wording is the point (a distinctive phrasing, a named
person's exact claim, a line the piece will return to). Paraphrase when only
the idea matters — quoting for authority what you could say plainer buries the
argument under someone else's paragraphs.

## Callout vs inline

Asides, tips, warnings → `> [!TIP]` / `> [!NOTE]` / `> [!WARNING]` only when
they would genuinely derail the argument inline — a detour the reader takes and
returns from. Otherwise leave it inline; callouts used for decoration teach the
reader to skip boxes.

## Code block vs inline code

Multi-line, runnable, or illustrative → fenced block. A single identifier or
flag → inline. A command someone will run gets its own block even if short —
copy-paste is the point.

## Paragraph shape

One job per paragraph: state it, support it, stop. Short paragraphs are for
weight, not for frequency — a page of one-line paragraphs is a list that
refused to admit it. End paragraphs on the load-bearing word.

## The numbered / headed long-form

Headings every few hundred words help readers who came to skim, but each
section must still connect by _therefore/but_ to the one before — a piece that
reads fine as independent sections is a list of articles wearing a spine-shaped
hat. Test: read only the first sentence of each section. If the piece's
argument survives, structure is doing its job; if not, the sections are
ornament.
