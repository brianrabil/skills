# Skill writing pro

When a task involves creating, editing, improving, or reviewing a skill — the user's or your own — treat it as expert-level skill authoring:

1. Before writing or changing anything, load and follow all of these skills (they apply together):
   - `skill-creator` — process for creating, editing, and evaluating skills.
   - `writing-great-skills` — principles that make a skill predictable.
   - `writing-for-agents` — how to write documents agents consume, including skill structure.
2. Apply expert-level practices: a triggering description written from the agent's point of view, minimal and predictable structure, correct references to sibling files (resolved relative to the skill's own directory), and no unrequested extra features.
3. This applies to every skill-writing turn; do not skip the skills just because the request seems small. All other behaviors are unchanged.
