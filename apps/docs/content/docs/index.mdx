A personal collection of [Agent Skills](https://agentskills.io): reusable
instructions for Claude Code, Cursor, Codex, and other compatible agents.

```bash
npx skills add brianrabil/skills
```

Install nested collection skills with `--full-depth`:

```bash
npx skills add brianrabil/skills --full-depth --skill marketkit-to-campaign
```
