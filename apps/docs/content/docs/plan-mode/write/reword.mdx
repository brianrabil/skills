`write-reword` is the first draft in Plan Mode's writing pack. It changes selected wording while preserving commitments, exact terms, and warranted uncertainty. It is not a summarizer or a substantive revision workflow.

## Example request

```text
Only reword the second sentence. Preserve connect(), its uncertainty,
and all surrounding text. Show the diff.
```

The skill identifies the exact occurrence, checks the requested boundaries, and reports mechanical comparisons separately from editorial judgments about meaning. Read-only proposals leave the source untouched.

## Current status

The skill and its local references exist. Its ID is `write-reword`. From a local checkout, use `skills add . --full-depth --skill write-reword` to discover the nested collection, or point the installer directly at `skills/plan-mode`.

Host invocation, behavioral evaluation, and human review remain pending for this draft. This preview is not a claim that the complete writing pack is available.

The skill works through instructions; it does not currently provide runtime-enforced scopes. No commit, publication, or delivery action is implied by a wording edit. Optional editor integration and review views are separate planned work.
