Marketkit separates campaign decisions from asset production. Approve the plan
first, generate only the scoped assets, then schedule and verify the launch.

```bash
npx skills add brianrabil/skills --full-depth --skill marketkit-to-campaign
```

## Workflow

| Skill                    | Use it when                                         | Result                                              |
| ------------------------ | --------------------------------------------------- | --------------------------------------------------- |
| `marketkit-to-campaign`  | A product, launch, or message needs a campaign plan | Channels, cadence, messages, voice, and asset scope |
| `marketkit-to-posts`     | The approved plan needs social copy                 | Channel-native posts                                |
| `marketkit-to-ads`       | The approved plan needs paid variants               | Headlines, body copy, and calls to action           |
| `marketkit-to-email`     | The approved plan needs email copy                  | Subject, preheader, body, and one call to action    |
| `marketkit-to-images`    | The approved plan needs visual assets               | Channel-sized images or production briefs           |
| `marketkit-to-schedule`  | Approved assets need dates and channels             | A posting schedule                                  |
| `marketkit-to-checklist` | The campaign is ready for preflight                 | An ordered publishing checklist                     |

Shared references define the asset inventory and working platform dimensions.
Platform requirements drift, so high-stakes campaigns should verify the current
official requirements before publication.
